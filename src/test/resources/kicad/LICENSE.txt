KiCad board fixtures for the board import tests (org.openpnp.instancelabs.kicad).

Each file below is a copy, or a stripped copy, of a published design. The copies
are used only as test input. Files larger than 1 MB are stored gzipped (*.gz)
and the tests read them through GZIPInputStream. The stripped copies were made
by a script that removes whole S-expression items (it never edits geometry);
the removed items have no pads and are not on Edge.Cuts, so the placements and
the board outline do not change.

The projects' logo, branding and marks are reserved, and derivative works must
remove them (items 4 and 5 of each project's LICENSE). These copies remove them:

  ftp.kicad_pcb.gz: the logo footprint G1 (mfg library) removed; the board
    text "Functional Test Placement REV00\n<<hash>>\n<url>" cut to
    "Functional Test Placement REV00\n<<hash>>"; the 3-D model references
    (model ...) removed.
  ftp0402.kicad_pcb.gz: the logo footprint G1 (mfg library) removed; the board
    text cut to "Functional Test Placement REV00 (0402)"; model references
    removed.
  pi-interface-k7.kicad_pcb: the two kibuzzard-* text footprints removed;
    model references removed.
  pi-interface-k10.kicad_pcb.gz: the five kibuzzard-* text footprints removed;
    model references removed (they held absolute designer paths).
  mobo.kicad_pcb.gz: the six pad-less logo footprints (LOGO twice,
    index:goblin, feeder:pulsar, index:logo_mask, the OSHW symbol) and the
    board text naming the project and the company removed.
  secondary-fid-pcb.kicad_pcb: unchanged.

The board is a KiCad port of the Arduino Nano V3.3 PCB design (originally made
for EAGLE and published by Arduino: https://store.arduino.cc/products/arduino-nano),
modified slightly by the port to avoid ERC/DRC errors. Credit: Arduino, and the
authors of the "Nano_KiCAD" port.
